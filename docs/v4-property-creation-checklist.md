# V4物件追加時の確認項目

## 承認済みの条件別標準（2026-10-18）

ユーザー確認済みの10物件を条件別標準として採用。[条件別標準](v4-conditional-content-standards.md)と[承認済み条件・本文参照一覧](v4-approved-standards.json)を先に確認し、同じ設備・契約条件の本文と書式を使う。物件固有の連絡先・料金・階数・ペット条件・契約条件を保持する。未確認の条件は推測しない。既存URL・物件を識別できるvariant名は維持する。

## アンケートボタン（2026-10-17）

- management_otherには、11300の任意回答の説明と「入居後アンケートに回答する」ボタンを含める。
- URLは https://guide.univ-life.com/survey.html?propertyNo=物件番号&source=shiori_public とし、対象物件の番号を設定する。11300の番号をそのまま複製しない。
- 新しい物件の全項目確認には、ボタンの表示と回答ページの物件No表示を含める。確認用の回答は送信しない。

## ペット飼育可能物件の標準書式（2026-10-18）

- 28900の4見出しを標準とする：「飼育できるペットと頭数」「飼育前に申請する」「共用部と室内での注意」「苦情があった場合」。すべて常時表示する。
- 種類・体重・頭数は物件の登録条件を保持する。20400は合計1匹、28900は合計2匹。いずれも犬（小・中型15kgまで）・猫（10kgまで）。他物件への適用時は推測せず登録条件を確認する。
- 「ペット飼育規約があります。」を標準で明記する。飼育条件・費用は「契約内容をご確認ください」と案内し、事前申請も明記する。
- 共用部で抱くかケージを使う、鳴き声・臭い・毛、汚損・破損、糞尿処理を同じ段落で案内する。苦情時は改善依頼と改善がない場合の飼育中止を案内する。
- variant名は物件を識別できるものを保持し、飼育禁止物件を飼育可能へ変更しない。

## エレベーター付き物件の搬入案内（2026-10-18）

- エレベーターありと確認できる物件だけ、搬入時の注意へ「搬入時はエレベーターを保護する」を追加する。
- 標準本文：エレベーターや共用部の壁・手すりなどを傷つけないようにしてください。搬入・搬出時は、必要に応じてエレベーターを養生してください。
- 現在の対象は20400・40100・52000・28900。登録元moving=base_ev_alが確認できる。オートロック付き、複数階、物件番号だけでエレベーターありと推測しない。未確認・なしの物件へは追加しない。
- 本文はcontent_blocksの対象物件のmoving variantへ登録し、「搬入時の注意を確認する」内にまとめる。他物件のvariantを無条件に複製しない。
- 今後追加する物件も、設備条件を確認して同じ標準文を使う。確認では、ありの物件での表示と、なし・未確認の物件での非表示を含める。

## インターネットの問い合わせ先の引継ぎ（2026-10-18）

- 「利用開始」の本文に提供会社・窓口が登録されている場合は、「インターネットにつながらない」にも同じ提供会社と直接の問い合わせ先を表示する。
- J:COMは登録済みの電話窓口を引き継ぐ。UCOM光レジデンスは登録済みの建物専用ページへつなぐ。一般の個別契約向け案内へ一律に置き換えない。
- 0net・ベイコム・イーブロード・個別契約回線の既存分岐を維持する。機器提供・料金・解約条件は本文の提供会社名だけから推測しない。

## 水道案内の標準書式（2026-10-18）

- [水道案内の標準書式](water-format-standard.md)に従う。11300の簡潔な見出し・説明と独立した電話・公式サイトボタンを標準とする。29000にも適用済み。
- 自治体・電話・受付時間・料金の請求方法は対象物件の条件を確認する。管理会社請求や定額の物件に水道局への開栓・直接請求を一律適用しない。
- variant名は既存の物件を識別できるものを保持する。
