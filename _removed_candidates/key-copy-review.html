鍵の管理・紛失時の対応

本文の見直し案です。公開中の本文は変更していません。費用・納期・返却条件は現在の案内を維持しています。

鍵は大切に保管する

入居時にお渡しする鍵は、入居者様専用です。紛失しないよう大切に保管してください。

現在の文言

鍵は紛失しないよう大切に保管してください / ご入居時にお渡しする鍵は、入居者様専用の大切な鍵です。 受け取り後は、紛失しないよう注意して保管してください。

オートロック扉を開け放しにしない

オートロック扉は自動で閉まります。 石や荷物で固定して開け放しにすることは禁止です。不審者の侵入を防ぐため、扉が閉まるようにしてください。

現在の文言

オートロック扉を開け放しにしないでください / エントランスのオートロック扉は、防犯のため自動的に閉まります。 石や荷物で扉を固定して開け放しにする行為は禁止です。不審者の侵入につながるため、ご注意ください。

来客を確認してから解錠する

来客や宅配業者が来たら、インターホンで確認してから解錠してください。

現在の文言

来客や宅配業者はインターホンで確認してください / 来客や宅配業者が来られた際は、インターホンで確認してから解錠してください。

追加の鍵は管理会社へ申込み（有料）

通常キーの費用の目安は、1本3,300円（税込）です。 種類によってはメーカーへの発注が必要となり、納品まで2〜4週間かかる場合があります。

現在の文言

追加の鍵は管理会社へお申し込みください（有料） / 通常キーの費用の目安は、1本あたり3,300円（税込）です。 鍵の種類によってはメーカー発注となり、納品まで2〜4週間かかる場合があります。

鍵を紛失したら、速やかに管理会社へ連絡

防犯のため、シリンダー（鍵穴部分）の交換が必要になる場合があります。 交換費用は入居者様のご負担となります。

現在の文言

鍵を紛失した場合は速やかにご連絡ください / 鍵を紛失した際は、速やかに管理会社へご連絡ください。 防犯のためシリンダー交換が必要になる場合があり、その費用は入居者様のご負担となります。

玄関ドアは必ず施錠する

エントランスのオートロックがあっても、お部屋の玄関ドアは必ず施錠してください。

現在の文言

オートロックがあっても玄関ドアを施錠してください / エントランスのオートロックは共用部の防犯設備です。各住戸の施錠に代わるものではありません。 玄関ドアは必ず施錠してください。

退去時は鍵をすべて返却する

入居時にお渡しした鍵は、退去立会い時にすべてスタッフへ直接お渡しください。 本数が不足すると紛失扱いとなり、シリンダー交換費用が発生します。

現在の文言

退去時はお渡しした鍵をすべて返却してください / ご入居時にお渡しした鍵の本数すべてを、退去立会い時にスタッフへ直接お渡しください。 本数が不足している場合は紛失扱いとなり、シリンダー交換費用が発生します。
