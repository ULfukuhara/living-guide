# J:COM案内の照合結果

更新日：2026年10月19日

J:COM登録28件のうち、現在公開中の24件すべてでインターネット項目のV4専用本文を使用しています。非公開は51000・44000・28000・41600の4件です。64500はインターネットのみ整備し、給湯確認待ちによる物件全体の量産スキップを維持しています。

[書式統一と44000公開停止の実施記録](20261019-v4-jcom-format.md)

## 照合結果

- 24件すべてで、登録コースと公開本文の下り最大速度が一致。無料対象コース・Wi-Fi条件・利用開始手続きを元の登録本文と照合し、内容を保持しています。
- 初回監査の233ブロックと追加91ブロックを読み戻し照合。現在の公開対象24件すべてに物件ごとのV4専用本文を設定しています。
- 公開画面にWi-Fi無料と自己用意ルーターの断定が併存する矛盾はありません。

## 確認・整理が必要な情報

- 公開対象の23件は、管理表のwifi_router_providedがFALSE、公開側は未設定です。画面では未確認として扱い、ルーターなしとは表示していません。Wi-Fi無料と事前設置・申込み後の貸与は区別が必要なため、機器の有無は一括変更していません。
- 接続不具合の窓口は元本文に合わせて一般窓口0120-999-000を保持しています。J:COM公式には技術窓口0120-99-3652もあり、今後分けて案内すると明確です。
- 元の登録本文は退去時の解約・機器返却を明記していません。契約ごとの確認が必要であり、解約不要とは断定していません。
