# V4 条件別の承認済み標準

承認日：2026年10月18日。ユーザーによる10物件のチェック完了を受け、現在の修正済み本文・表示形式・条件分岐を、同じ条件の物件に適用する標準として採用する。

## 適用方法

- 作成・追加・修正前に、対象物件の設備、請求方法、契約条件、自治体、サービス提供会社を確認する。
- 下表で条件が一致する承認済み案内を選び、共通の構成・文言を使用する。物件全体を丸ごと複製しない。
- 電話番号・受付時間・URL、料金、頭数・体重、区画・階数、個別契約の条件は対象物件の情報に合わせる。未確認を「あり」「無料」と推測しない。
- 既存の物件を識別できるvariant_keyとURLを維持する。標準採用のためだけに全物件を同じvariant名へ変更しない。
- [承認済み条件・本文参照一覧](v4-approved-standards.json)に10物件の条件、選択された本文のvariant・ブロックID・確認時のハッシュを保存。確認時本文は[承認済み本文スナップショット](v4-approved-content-snapshot.json)に保存する。共通本文と条件による非表示も含め、実際の表示内容を基準にする。

## 条件別の標準

| 条件・項目 | 標準として使用する内容 | 適用時に確認する事項 |
|---|---|---|
| IH＋ガス給湯 | 10100・11300・29000、今回確認した27500の分岐。IHとガス給湯を区別し、ガスコンロのトラブルカードを表示しない | 27500はIH＋ミツワLPガス給湯。IHだけを理由にガス手続きを消さない |
| ガスコンロ＋ガス給湯 | 40100を基準に整えた20400・52000を含む現行案内 | 都市ガス／LPガス、会社、地域別窓口 |
| オール電化・電気温水器 | 10400の現行案内。「お湯が出ない」は電気温水器の状態を確認 | 深夜電力契約が必要になる場合がある旨。ガスの確認案内を混在させない |
| セントラル給湯 | 60300の現行案内。「お湯が出ない」はセントラル給湯の状況を確認 | 検針・請求・無料使用量等の物件条件を保持 |
| 電気の連絡先 | 現在の提供会社に応じた電話・手続きボタンの形式 | 管理会社検針・請求と、入居者による供給会社契約・停止手続きを区別 |
| 水道局への直接申込み・請求 | 11300・29000の[水道標準書式](water-format-standard.md)。手続き→連絡先→料金→検針 | 自治体、電話・受付時間、公式URLを確認 |
| 管理会社検針・定額等の水道 | 20400・27500・40100・60300の該当条件の現行案内 | 定額、使用量、超過料金の条件を保持。水道局への直接申込みへ置換しない |
| J:COM無料Wi-Fi・ルーターの用意不要 | 29000の現行案内。320M・Wi-Fi無料、ルーターを自分で用意する必要なし、利用開始手続きと直接窓口 | wifi_router_provided=TRUE。無料だけから機器提供の有無を推測しない |
| その他のインターネット | 0net・ベイコム・e-Broad・UCOMの該当する現行案内。「困ったとき」にも登録済みの直接窓口を引き継ぐ | 無料範囲、機器、利用開始・停止条件は提供会社ごとに確認 |
| ポストなし | mailbox=no_postならポスト案内を非表示 | 10100の設定。建物にポストがない場合に適用 |
| 階数でポストの有無が異なる | 60300の冒頭注意を標準とし、操作説明は設置されている部屋向けと明記 | 60300は2階以上のみ。別物件へ同じ階数を転用しない |
| 宅配ボックスあり | 通知票・アプリによる通知を含む現行の共通構成。受取方法、禁止事項、連絡先を案内 | カード式・固定番号式等を区別。出動費5,500円や不定期訪問時に無償対応する場合がある案内は、同じ運用・料金の確認がある物件に適用 |
| 宅配ボックスなし | TOPの代替表示を用意し、エアコンを使う場合は室内機の画像 | 宅配ボックスがあるように表示しない |
| エレベーターあり | 搬入時の注意に、壁・手すり等の傷防止と必要に応じた養生の案内 | 20400・40100・52000・28900。なし・未確認の物件には追加しない |
| 温水洗浄便座あり | 10400・20400の現行案内 | 明示確認がある場合のみ。指示がなければ温水洗浄便座なしの案内を使用 |
| 共用部 | 現行の共用部禁煙案内を引き継ぐ | 共用部以外まで制限を広げない |
| 自転車置き場あり | 現行の免責案内。管理会社は責任を負いかねる旨と、管理会社の故意・過失の場合の例外、警察・管理会社への連絡案内 | 有料・無料、指定区画、台数、ステッカー料金等を保持 |
| ペット飼育可 | 28900を基準とする4見出しと「ペット飼育規約があります。」、条件・費用は契約内容の確認を促す | 20400は合計1匹、28900は合計2匹。犬15kg・猫10kg等の個別条件を確認。飼育不可には適用しない |
| ごみ | [ごみ標準書式](trash-format-standard.md)の構成 | 自治体・地域、収集日、集積場所、民間回収を物件ごとに設定 |
| 困ったとき・騒音 | 確認済みの現行内容を折り畳まず表示 | 一度戻した契約条文による増補を復活させない |
| 合鍵・室内設備・床 | 確認済みの現行文言。合鍵は作成可能・ご自身の責任で、床の表記、設備の改造・交換・穴あけ等は基本禁止 | 個別の契約・鍵方式による条件を保持 |
| 解約・更新 | 詳しい案内の書式を統一し、予告期間・解約日・更新条件は契約書の確認を促す | CKU基本の20400・27500でも一般契約がある。2か月前・3月22日等は例として扱い、全室共通と断定しない。旧契約の自動更新も一律変更しない |
| 解約フォーム | 有効と確認された現行10物件の表示条件を保持 | 新規物件も公開運用を確認して登録元・公開値を一致させる |
| アンケート | 任意回答の説明と入居後アンケートボタン | URLのpropertyNoを対象物件へ設定する |

## 完了基準

対象物件のローカル画面で条件に応じた表示・非表示を確認する。同じ条件で標準と書式が一致すること、物件固有の料金・窓口・設備条件が保持されていること、320px／375px幅で崩れないことを確認して公開し、公開後も対象ページを確認する。

今回の標準登録では、確認済み公開画面の再変更は行わない。今後の物件追加・同条件の修正に、この標準と既存の条件分岐を使用する。
