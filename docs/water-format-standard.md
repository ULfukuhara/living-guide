# 水道案内の標準書式

2026年10月18日：11300の簡潔な見出し・本文・独立したボタンの書式を標準とする。29000も同じ書式へ統一。

## 水道局へ使用開始・中止を申し込む物件

次の順序でcontent_blocksを作成する。

1. 「入居日までに水道の使用開始手続きをする」：開栓手続きと使用開始日を伝える説明。
2. 自治体公式の使用開始・中止手続きボタン。
3. 「使用開始・中止の連絡先」：窓口名・受付時間と、電話番号を表示した独立した電話ボタン（tel:）。
4. 「水道料金は水道局から直接請求されます」：入居者負担と支払い方法の案内。
5. 「水道メーターの付近に物を置かない」：検針の妨げを防ぐ案内。

本文中に同じURLを重ねて書かず、手続きはボタンにまとめる。各見出しは常時表示する。

## 物件ごとの適用条件

- 共通なのは書式と説明の構成。物件所在地・水道局・電話番号・受付時間・公式URLは必ずその物件の公式案内を確認する。
- 管理会社検針・管理会社請求・定額・使用量による超過料金の物件に、水道局への開栓・直接請求を一律適用しない。登録済み条件を保持して、その条件に応じた見出し・本文を使う。
- variant_keyは物件を識別できる既存名を保持し、11300の名前へ一律変更しない。
- 今回の表示変更は29000のみ。11300を基準として維持し、他8物件は変更していない。
